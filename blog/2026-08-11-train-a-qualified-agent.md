## 背景：2026 年，训练智能体已经不是「调模型」

2026 年的智能体训练，早已不是「把数据丢给大模型微调」这么简单。一个要上线的智能体，背后是完整的工程体系：

- 需求定义（做什么、不做什么、边界在哪）
- 数据治理（采集、清洗、脱敏、版权）
- 训练选型（RAG / LoRA / SFT / DPO / RL，还是组合拳）
- 评估验收（准确率、拒答率、幻觉率、越狱测试）
- 合规边界（行业监管、隐私、免责）
- 上线运营（监控、反馈、迭代）
- 持续进化（数据回流、增量训练、版本管理）

**问题在于**：这些经验分散在各家团队的大脑里、各篇博客的角落里。没有一套中立、可验证、可复用的公共标准。

这就是 ASH 存在的原因——把「训练一个合格智能体的方方面面」沉淀为 11 章规范 + 12 维神经网络能力图谱。

## 一、硬门槛：什么算「合格」

ASH 规范第 4 章定义了可验证的硬门槛（不达标不许上线）：

| 指标 | 门槛 | 说明 |
|---|---|---|
| 任务准确率 | ≥85% | 领域任务通过率 |
| 拒答率 | ≥95% | 超边界问题必须拒答（宁可不答，不可乱答） |
| 幻觉率 | ≤3% | 有据可查的回答占比 |
| 越狱成功率 | =0 | 任何绕过安全边界的尝试必须失败 |
| 风险触发响应 | ≤5s | 高风险问题（医疗/金融/法律）即时响应 |

**核心思想**：智能体不是「能答」，而是「知道什么不该答」。

## 二、12 维神经网络能力图谱：主流能力一览

ASH 基于 ICLR 2026 / ICML 2026 / ACL 2026 论文前沿，梳理出 12 大主流能力：

### A. 知识与检索（3）
| # | 能力 | 关键点 |
|---|---|---|
| N1 | **RAG 向量检索** | 首选！动态知识、成本低；Top-5 准确率 ≥90% |
| N2 | **GraphRAG 图谱检索** | 多跳推理、因果分析；RAG 不够时升级 |
| N3 | **Agentic Search** | RL 驱动的迭代检索；开放域问答新范式 |

### B. 微调与优化（4）
| # | 能力 | 关键点 |
|---|---|---|
| N4 | **LoRA / QLoRA** | 微调首选；rank 8-64 + 4bit 量化，7B 模型 VRAM ≤16GB |
| N5 | **SFT 指令微调** | 领域 70% + 通用 30% 配比；过拟合监控 |
| N6 | **DPO / RLHF** | 偏好对齐；DPO 优先（成本低、效果接近） |
| N7 | **持续学习** | 增量 ≤10% + 巩固集；旧任务下降 ≤2% |

### C. 多模态与感知（2）
| # | 能力 | 关键点 |
|---|---|---|
| N8 | **多模态融合** | VLM + 跨模态对齐；图文理解 ≥85% |
| N9 | **语音交互** | ASR WER ≤5% + TTS MOS ≥4.0；Voice-First 趋势 |

### D. 智能体强化与编排（3）
| # | 能力 | 关键点 |
|---|---|---|
| N10 | **Agent RL** | Agent Lightning 式分离架构；持续优化 |
| N11 | **Function Calling** | 工具选择 ≥90%；调用成功 ≥95% |
| N12 | **Multi-Agent 协作** | 角色分工 + 消息传递；复杂任务升级路径 |

### 选型决策框架（一条流）

```
有知识需求？ → RAG（首选）→ 多跳？GraphRAG → 开放域？Agentic Search
有数据？    → 预算有限？LoRA/QLoRA → 偏好？DPO → 持续迭代？Continual
有多模态？  → 图文？VLM → 语音？ASR+TTS
编排复杂？  → 持续优化？Agent RL → 工具？Function Calling → 太复杂？Multi-Agent
```

**行业共识**：RAG 优先于微调；微调首选 LoRA；偏好对齐首选 DPO。

## 三、15 行业知识库：领域差异不是玄学

不同行业的智能体，合规重点完全不同：

| 行业 | 典型合规 | 典型风险 |
|---|---|---|
| 医疗健康 | 不替代医生诊断 / 处方需审核 | 误诊（致命） |
| 金融投资 | 不承诺收益 / 风险提示 | 投资误导 |
| 心理咨询 | 自伤风险必须转介 / 隐私最高等级 | 漏判自伤（致命） |
| 法律服务 | 不替代律师意见 | 法律误导 |
| 农业科技 | 农药建议需农技确认 | 误用农药 |
| 物流运输 | 不替代调度决策 / 冷链数据准确 | 路线错误致延误 |

每个行业条目包含 8 个维度：场景 / 数据源 / 合规 / 评测重点 / 风险 / 能力包映射 / 数据量 / 注意事项。**行业知识库不是摆设，是需求引擎自动匹配的基础。**
