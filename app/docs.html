概览

ASH API 提供 15 个端点，覆盖需求评估、知识卡查询、神经网络能力推荐、评估报告生成、客户管理与词元计费。

环境地址
本地http://localhost:8933
公网https://sgmt-taojing.github.io/agent-training-standards/（静态 + 本地 API）

鉴权

两种模式：

模式Header说明
免费引流无需评估/知识卡/报价等公共接口可直接调用，返回结果但不记账
Key 鉴权X-API-Key: ash_xxx关联客户账户，调用扣词元，返回 billing 字段

也支持 Authorization: Bearer ash_xxx。

POST /api/auth/register

免费 POST/api/auth/register

注册新客户，获得 API Key（首月赠送 100 万词元免费额度）。

请求体

参数类型必填说明
namestring是客户名称
contactstring否联系方式

示例

curl -X POST http://localhost:8933/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"我的公司","contact":"me@example.com"}'

响应

{"ok":true,"clientId":"Cmsnu85lg","apiKey":"ash_xxx",
 "freeQuota":1000000,
 "warn":"apiKey 仅展示一次，请妥善保存"}

POST /api/engine/analyze

免费/Key POST/api/engine/analyze

核心端点：自然语言 → 结构化需求卡（行业/合规/路径/匹配/报价）。带 Key 时记账。

参数类型必填说明
querystring是训练方向描述（≤2000字）
industrystring否行业提示
targetstring否目标形态（默认"对话助手"）

POST /api/billing/quote

免费 POST/api/billing/quote

报价预估：给定方向与月调用量 → 费用区间。

GET /api/auth/me 需 Key

GET/api/auth/me

获取当前客户信息：余额、免费额度、本月调用、本月词元。

curl http://localhost:8933/api/auth/me -H "X-API-Key: ash_xxx"

GET /api/auth/usage 需 Key

GET/api/auth/usage?limit=20

获取调用明细（最多 100 条）。

POST /api/auth/subscribe 需 Key

POST/api/auth/subscribe

开通年度订阅（¥3,900/年，含 2,000 万词元）。从余额扣款，额度不足返回 400。扣费顺序：订阅额度 → 免费额度 → 余额。

curl -X POST http://localhost:8933/api/auth/subscribe \
  -H "X-API-Key: ***"

POST /api/auth/recharge-request 需 Key

POST/api/auth/recharge-request

提交充值申请（最低 ¥500，方式：bank/alipay/wechat/invoice）。状态流转：pending → confirmed（运营确认入账）| rejected（驳回）| cancelled（客户取消）。

curl -X POST http://localhost:8933/api/auth/recharge-request \
  -H "Content-Type: application/json" -H "X-API-Key: ***" \
  -d '{"amount":5000,"method":"alipay","note":"年度预算"}'
POST/api/auth/recharge-cancel

取消待确认申请单。Body: {"orderId":"ORD-xxx"}

GET /api/auth/orders 需 Key

GET/api/auth/orders

我的充值申请单列表（最近 20 条）。

POST/api/auth/recharge

账户充值。Body: {"amount":500}

GET /api/auth/reports 需 Key

GET/api/auth/reports

获取历史评估报告列表。

快速开始（3 步）

# 1. 注册获取 Key
curl -X POST http://localhost:8933/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"我的公司"}'
# → {"apiKey":"ash_xxx", ...}

# 2. 评估需求
curl -X POST http://localhost:8933/api/engine/analyze \
  -H "Content-Type: application/json" \
  -H "X-API-Key: ash_xxx" \
  -d '{"query":"训练一个医疗问诊智能体"}'
# → 需求卡（行业/合规/匹配/报价/billing）

# 3. 下载报告
curl -X POST http://localhost:8933/api/report/pdf \
  -H "Content-Type: application/json" \
  -d '{"query":"训练一个医疗问诊智能体","industry":"医疗健康"}'
# → {"downloadMd":"/api/report/file/RPT-xxx.md", ...}
