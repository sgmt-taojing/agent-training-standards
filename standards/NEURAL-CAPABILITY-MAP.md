## 12 大主流能力（按训练流程分组）

### A. 知识与检索（3）

| # | 能力 | 核心技术 | 适用场景 | 门槛/指标 | 选型建议 |
|---|---|---|---|---|---|
| N1 | **RAG 向量检索** | Embedding + Vector DB（FAISS/Milvus/pgvector）+ Reranking | 动态知识问答、文档检索、KB 优先策略 | 检索准确率 Top-5 ≥90%；检索延迟 P95 <200ms | **RAG 优先于微调**（2026 行业共识：大多数场景 RAG 够用，微调仅限特定优化） |
| N2 | **GraphRAG 图谱检索** | 知识图谱 + 图遍历 + 实体关系推理 | 多跳推理、因果分析、跨文档关联 | 多跳准确率 ≥85% | 当 RAG 单跳不够时升级（如医疗辨证链路） |
| N3 | **Agentic Search 智能搜索** | RL 驱动的迭代检索→评估→再检索 | 开放域问答、市场调研、多源融合 | 答案有据率 ≥95%；搜索轮次 ≤5 | 2026 新范式：从「被动检索」到「主动搜索试错」 |

### B. 微调与优化（4）

| # | 能力 | 核心技术 | 适用场景 | 门槛/指标 | 选型建议 |
|---|---|---|---|---|---|
| N4 | **LoRA / QLoRA 参数高效微调** | 低秩适配矩阵（rank 8-64）+ 量化（4bit/8bit） | 领域适配、风格定制、成本敏感训练 | 与全参微调差距 ≤3%；VRAM ≤16GB（7B 模型） | **微调首选**（2026 共识：LoRA/QLoRA 是唯二推荐的微调方式） |
| N5 | **SFT 指令微调** | 指令-回答对 + ChatML 格式 + Epoch 1-5 | 基础能力注入、对话格式对齐 | 领域准确率 ≥85%；过拟合监控（train/val loss 分叉即停） | 所有微调的起点；配比领域 70% + 通用 30% |
| N6 | **DPO / RLHF 偏好对齐** | 偏好对（chosen/rejected）+ 直接偏好优化 | 安全对齐、风格偏好、拒答行为 | 偏好胜出率 ≥70%；偏好对 ≥ 数据集 5% | DPO 优先（2026 主流：RLHF 成本高，DPO 效果接近且简单） |
| N7 | ** continual learning 持续学习** | 增量数据（≤原 10%）+ 旧知识巩固集 + EWC/Replay | 防灾难性遗忘、月度迭代 | 旧任务下降 ≤2%；新任务达标 | 每月≤1 次增量；必须带巩固集 |

### C. 多模态与感知（2）

| # | 能力 | 核心技术 | 适用场景 | 门槛/指标 | 选型建议 |
|---|---|---|---|---|---|
| N8 | **多模态融合** | Vision-Language Model（CLIP/BLIP/Qwen-VL）+ 跨模态对齐 | 图文问答、视觉诊疗、文档理解 | 图像理解准确率 ≥85%；图文一致率 ≥90% | 当文本不够时升级（如舌诊/面诊必须多模态） |
| N9 | **语音交互** | ASR（Whisper/Paraformer）+ TTS（Edge-TTS/Seed-TTS）+ 流式低延迟 | 语音助手、实时对话、无障碍交互 | ASR WER ≤5%；TTS MOS ≥4.0；端到端延迟 <500ms | **Voice-First 趋势**（未来无界面方向，提前布局） |

### D. 智能体强化与编排（3）

| # | 能力 | 核心技术 | 适用场景 | 门槛/指标 | 选型建议 |
|---|---|---|---|---|---|
| N10 | **Agent RL 强化学习** | Agent Lightning（训练-智能体分离）/ AgentRL / PPO + 环境模拟 | 智能体持续优化、工具调用学习、多步决策 | 任务完成率 ≥85%；奖励收敛稳定 | 2026 新范式：零侵入 RL 让任何 Agent 持续进化（微软 Agent Lightning） |
| N11 | **Function Calling 工具调用** | 结构化函数描述 + 多步调用 + 结果整合 + 错误重试 | 业务系统集成、工具编排、工作流自动化 | 工具选择准确率 ≥90%；调用成功率 ≥95% | 智能体编排核心能力（与 N10 RL 协同进化） |
| N12 | **Multi-Agent 协作** | 角色分工（Planner/Executor/Critic）+ 消息传递 + 冲突解决 | 复杂任务分解、大规模并行、质量内审 | 子任务完成率 ≥90%；协作开销 ≤30% | 当单 Agent 能力瓶颈时升级（ICLR 2026 多智能体论文爆发） |

## 能力选型决策框架

```
                    ┌─ 仅需知识检索？──→ N1 RAG（首选，成本低）
                    │
                    │  ├─ 多跳推理？──→ N2 GraphRAG
                    │  │
                    │  └─ 开放域/多源？──→ N3 Agentic Search
                    │
   有数据？─→ 微调  │
                    │  ├─ 预算有限？──→ N4 LoRA/QLoRA（≤16GB VRAM）
                    │  │
                    │  ├─ 基础注入？──→ N5 SFT
                    │  │
                    │  ├─ 安全/偏好？──→ N6 DPO
                    │  │
                    │  └─ 持续迭代？──→ N7 Continual Learning
                    │
   有图像/语音？──→ 多模态
                    │  ├─ 图文/Vision？──→ N8 Multimodal
                    │  └─ 语音优先？──→ N9 Voice
                    │
   编排复杂？──→ 智能体
                    │  ├─ 持续优化？──→ N10 Agent RL
                    │  ├─ 工具调用？──→ N11 Function Calling
                    │  └─ 任务太复杂？──→ N12 Multi-Agent
```

## 与训练规范的集成

- **规范第 2 章（数据）**：RAG 场景需准备向量检索语料；微调场景需 SFT/DPO 数据
- **规范第 3 章（训练）**：N4-N7 为微调能力选型章节的直接扩展
- **规范第 4 章（评估）**：N1-N3 评估检索准确率；N4-N7 评估微调指标；N10-N12 评估任务完成率
- **规范第 5 章（上线）**：N1-N3 需部署向量库；N9 需 ASR/TTS 服务；N10 需环境模拟
- **能力包映射**：N1-N3 → agent-orchestration-pack（KB 优先三级）；N4-N7 → training-pipeline-pack；N8 → vision-diagnosis-pack；N10-N12 → agent-orchestration-pack
